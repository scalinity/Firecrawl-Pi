While connected
The normal MCP watcher notices edits and incrementally updates the index. During a pending update, CodeGraph can flag stale files.
Between sessions
Edits made while CodeGraph is inactive are reconciled on the next MCP connection. You can also run codegraph sync explicitly.
What still needs checking
Static analysis can miss dynamic behavior. A missing edge is not proof that no path exists; tests and runtime checks establish what actually happens.

# issue: Pi5 16K PageSize Kernel Incompatible Software | state=closed comments=39 created=2023-10-21T14:25:15Z updated=2025-07-05T22:28:57Z
## issue body (verbatim)
This issue will be a public tracker for 16K pagesize incompatible software. I made a similar post in the bookworm beta forum thread but that is still not public.

Feel free to add your own incompatible software as a comment and I will add it to this post.

Much of this list is thanks to Asahi linux wiki https://github.com/AsahiLinux/docs/wiki/Broken-Software

Broken software:
- f2fs
- FEX
- hardened_malloc
- jemalloc
  - Geekbench 6 (< 6.2.2)
  - Minecraft Java (on versions and launchers without the <3.3.2 lwjgl native jemalloc patch)
  - rust
- fd
- Wine ARM64
- Wine x86_64 through Box64
- Box86
- Zig
- All Chromium based applications (pre-102)
  - qt5-webengine
  - qt6-webengine (QtPdf)
- libvirt/QEMU/KVM (fixed in versions newer than bookworm has)
- All Android applications (only 4k header compatible, https://reviews.llvm.org/D55029)
  - Minecraft Bedrock Launcher
- Most armv6/armv7 software
  - [Minecraft Pi Reborn](https://github.com/Botspot/pi-apps/pull/2493#issuecomment-1836200199)
- Scratch3
- [Flycast](https://github.com/flyinghead/flycast/issues/1288)
- [DOSBox](https://github.com/realnc/dosbox-core/issues/57)
- [btrfs](https://github.com/raspberrypi/bookworm-feedback/issues/136) (should be fixed in newer linux kernels or with newly generated btrfs storage I think.. https://www.spinics.net/lists/linux-btrfs/msg120249.html)
- [Musescore](https://github.com/musescore/MuseScore/issues/20342) - (< 4.2.0)
